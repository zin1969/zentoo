## 2. Value Object 採用理由

## なぜプリミティブではダメか
- [ ] 値に業務上の意味がある
- [ ] 判定・計算・制約ルールが存在する
- [ ] 誤った値が入ると業務ロジックが破壊される

### enum を使わない理由（該当する場合）
- [ ] ドメイン知識を Model に閉じ込めたくない
- [ ] Rails 依存を避けたい
- [ ] 振る舞いを持たせたい
