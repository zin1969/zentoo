# 機能の大枠

- 資産の開始残高を登録できる
- 日々の仕訳（お買い物）を登録できる
- 登録した仕訳を一覧で確認できる
- 残高（資産・負債）と月次の支出を確認できる（M3 で実装中）
- ログイン（API・画面とも実装済み。ユーザー登録画面は作らない。開発用ユーザーは seeds で作成）

## 勘定科目の持ち方

- 費用科目・資本科目は全ユーザー共通（`user_id IS NULL`）。ユーザー間の比較や傾向分析のため。ユーザー独自の費用科目を追加する場合は、共通科目の下に置く（独自科目も親をたどって共通科目に集計できるようにする）
- 資産・負債科目（現金、銀行口座、カード）はユーザー固有（`user_id` = 持ち主）
- 共通科目は追記のみ。名前の意味を変えない・削除しない（使わなくなる場合は廃止の印を付ける）。ユーザーからは更新・削除できない
- 仕訳登録・開始残高登録では、科目が「共通科目、または自分の科目」であることを DB 関数で確認する。存在しない科目と他人の科目は区別せず 404 を返す
