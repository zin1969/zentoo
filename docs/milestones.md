# マイルストーン

現状は [inventory_2026-10-27.md](inventory_2026-10-27.md) を参照。

## 進め方のルール

- マイルストーンは「ユーザーができること」で区切る。レイヤー（API だけ・画面だけ）では区切らない。
- **完了の定義（全マイルストーン共通）**: 次の4つがそろって、実際に動くこと。
  1. API（RSpec 通過）
  2. Web 画面（実機で操作して確認）
  3. 仕様書（OpenAPI / `apps/api/docs/interfaces/rest`）の更新
  4. CI が緑
- 同時に進めるのは1つだけ。完了するまで次に着手しない。途中で思いついた作業は該当マイルストーンの末尾か「後回し」に書く。
